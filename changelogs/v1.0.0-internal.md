# DevxyzIDE Pro Version `1.0.0-internal` Changelog

## Important note

DevxyzIDE Pro is created, developed, and owned by Jay-Ar Lee Espiritu. It is an
independent project and is not affiliated with the original AndroidIDE project.
DevxyzIDE Pro is built on open-source software released under the GNU General
Public License v3.0.

## Additions

- DevxyzIDE Pro is a new, separate app (package `com.jepongdevxyz.pro`) that
  installs alongside DevxyzIDE, with its own data, files and terminal.
- Donate: the Donate action on the home screen now opens an in-app sheet with a
  GoTyme Bank InstaPay QR code — scan it with GCash, Maya, or any InstaPay bank
  app to support the project.
- About: an ownership disclaimer is now shown under the app name.

## Removals

- About: the Telegram group, Telegram channel, Contribute and Contributors
  entries have been removed.

## Bug fixes

- This release is based on the DevxyzIDE 17602 code base, which includes the
  full setup and build fix chain: first-time tool setup now completes reliably,
  certificate errors during setup downloads are fixed, Gradle temp-directory
  and stale-lock problems are resolved, the IDE's own Gradle plugins resolve
  from a bundled local repository, and the log sender plugin is bundled with
  the app.

## Improvements

- Full "DevxyzIDE Pro" branding across the whole app, in every language.
- About and Documentation links now point to the DevxyzIDE Pro GitHub
  repository, and the contact email is now businessdevgithubjepong@gmail.com.
- About: the version line now shows the real app version, marked (official),
  and the header layout has been tightened.

We believe that you'll have a delightful experience using DevxyzIDE Pro `1.0.0-internal`!
